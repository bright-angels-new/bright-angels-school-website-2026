HERE TO HELP

Helpful information for parents.

Quick answers to common questions about applying to Bright Angels Junior School.

What happens after I submit an application?

Keep the application reference number shown after submission. The school will review the information and update the application status.

How do I check my child's application?

Open the Parents section, enter the application reference number and the child's full name exactly as entered on the application form, then select Check application status.

What do the application statuses mean?

Pending means the application is awaiting review. Under Review means the school is assessing the application. Approved means the application has been accepted. Rejected means the application has not been accepted.

Which classes can I apply for?

Applications are available for Baby Class, Middle Class, Top Class and Primary 1 to Primary 7, subject to the classes currently open for applications.

What if I lose my application reference?

Contact the school using the telephone numbers or email in the Contact section and provide the child's full name and guardian details so the school can guide you.

How can I contact the school?

Call +256 755 660 550 or +256 525 136 626, email brightangels26@gmail.com, or send a message using the contact form on this page.
